# Mi Planta Viva

**Mi Planta Viva** es un simulador web educativo que permite practicar el cuidado básico de una planta mediante decisiones interactivas. El usuario selecciona una especie, observa sus indicadores y realiza acciones de mantenimiento para favorecer su crecimiento.

## Objetivo general

Promover el aprendizaje de hábitos de cuidado y responsabilidad ambiental mediante una experiencia digital interactiva que permita reconocer algunas necesidades básicas de las plantas.

## Funcionalidades

- Selección de cinco especies: potus, monstera, orquídea, helecho y albahaca.
- Indicadores de agua, luz, salud, nutrientes y humedad del suelo.
- Acciones de cuidado: regar, revisar la luz, podar, abonar, revisar la tierra e inspeccionar posibles plagas.
- Simulación del paso de los días y cambios en las necesidades de la planta.
- Etapas de crecimiento, puntos y niveles de experiencia.
- Misiones diarias y diario de acciones.
- Diseño adaptable a computadoras, tabletas y teléfonos.

## Tecnologías utilizadas

- **HTML5:** estructura del simulador.
- **CSS3:** diseño visual y adaptación a diferentes pantallas.
- **JavaScript:** lógica de interacción y simulación.

No requiere instalar programas, librerías ni dependencias externas.

## Cómo ejecutar el simulador

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic en `index.html`.
4. El simulador se abrirá en el navegador.

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube los archivos `index.html` y `README.md` a la raíz del repositorio.
3. Entra en **Settings** y luego en **Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios. GitHub Pages generará un enlace público cuando termine la publicación.

## Uso educativo

El simulador puede utilizarse como recurso de educación ambiental para conversar sobre las necesidades de las plantas, la observación, la toma de decisiones y la responsabilidad en el cuidado de los seres vivos.

## Consideraciones

Esta aplicación presenta un modelo simplificado con fines educativos. No sustituye las recomendaciones de jardinería específicas para cada especie. Las necesidades reales dependen de factores como el clima, la estación, el tipo de sustrato, el tamaño de la maceta y las condiciones del espacio.
